# LOG

Append-only chronological log of ingestion events and flags. Newest entries at the bottom.

Format:
```
## YYYY-MM-DD HH:MM — <source filename>
- Document type: <classification>
- Extracted: N people, N commitments, N risks, N decisions.
- New entities: <list or "none">
- Flags / ambiguities: <list or "none">
- Sensitive-data flags: <list or "none">
```
